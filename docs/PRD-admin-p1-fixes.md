## 1. ปัญหา (ภาษาคนทั่วไป)

ทีมตรวจอ่านโค้ดจริงแล้วยืนยันว่าพัง 8 เรื่อง:

1. **ค้นหาบนมือถือใช้ไม่ได้** — กดปุ่มค้นบนมือถือได้แค่ช่องพิมพ์เปล่า พิมพ์แล้วหาย ไม่มีผลอะไรเลย ส่วนบนคอมปุ่มเดียวกันเปิดแผงค้นหาจริง
2. **เมนูหลอกตา** — เมนู "นัดหมาย" โชว์ให้คนตอบแชท (AGENT - สิทธิ์คนตอบแชท) เห็น แต่ระบบกันสิทธิ์ไล่กลับไปหน้าตอบแชททุกครั้ง กดไปก็เจอแค่หน้าหมุน
3. **ปุ่มออกมี 2 ท่า** — แถบข้างกดแล้วออกเลย ไม่ถามก่อน แถมใช้คีย์บอร์ดกดไม่ได้ ส่วนรูปโปรไฟล์มีถามก่อน "ต้องการออกจากระบบหรือไม่"
4. **หน้าต่างยืนยันปิดได้ตอนกำลังรอ** — ตอนกำลังลบ/กำลังสั่งงาน ปุ่มยกเลิกล็อกแล้ว แต่กดปุ่ม Escape (ปุ่มหนีบนคีย์บอร์ด) หรือคลิกพื้นหลังยังปิดหน้าต่างได้ คนใช้นึกว่ายกเลิกแล้วแต่งานทำไปแล้ว
5. **กดลบเบิ้ลส่งคำสั่งซ้ำ** — หน้าคำร้องกดยืนยันลบ 2 ทีติดตอนเน็ตช้า ส่งคำสั่งลบ 2 ครั้ง
6. **เมนูมือถือคนใช้คีย์บอร์ดหลงได้** — เมนูเลื่อนปิดไปแล้วแต่ยังเอาปุ่ม Tab (ปุ่มเลื่อนช่อง) ไปโดนลิงก์ที่ซ่อนอยู่ได้ กด Escape ก็ไม่ปิด
7. **หน้าต่างเตือนหมดเวลาโปรแกรมอ่านจอไม่รู้จัก** — หน้าต่าง "Session Expiring Soon" (เตือนว่าใกล้หลุดจากระบบ) ทำเอง ไม่ได้ใช้หน้าต่างกลาง โปรแกรมช่วยอ่านจอ (โปรแกรมช่วยอ่านให้คนมองไม่เห็นฟัง) ไม่รู้ว่าเป็นหน้าต่างเตือน
8. **พิมพ์ค้นหารัวๆ ผลเก่าทับผลใหม่** — หน้าคำร้องพิมพ์ค้นหาเร็วๆ ตอนเน็ตช้า ผลเก่าที่มาช้ากว่าทับผลใหม่ที่พิมพ์ล่าสุด

คำที่อธิบายครั้งแรกในใบนี้:
- **pending** = ช่วงกำลังรอผล เช่น กดลบแล้วเน็ตยังหมุนอยู่
- **guard** = ตัวกัน เช่น กันกดปุ่มซ้ำตอนกำลังรอ
- **inert** = สั่งให้เบราว์เซอร์มองข้ามส่วนที่ซ่อน ไม่ให้ Tab ไปโดน
- **focus trap/restore** = ขังปุ่ม Tab ไว้ในหน้าต่างที่เปิดอยู่ และคืนตำแหน่งเดิมตอนปิด

## 2. การตัดสินใจที่ต้องเจ้าของยืนยัน (2 ข้อ)

- **D1 (NAV-02): เลือกทางไหน** — (ก) เอาเมนูนัดหมายออกจากคนตอบแชท ให้เมนูตรงกับตัวกันสิทธิ์ (แนะนำ เพราะตัวกันสิทธิ์ล็อก AGENT ไว้ที่หน้าตอบแชทชัดเจน ปลอดภัยกว่า) หรือ (ข) เปิดให้คนตอบแชทเข้าหน้านัดหมายได้จริง (ต้องแก้ตัวกันสิทธิ์ = เปิดสิทธิ์เพิ่ม ต้องคิดเรื่องความปลอดภัย)
- **D2 (A11Y-02 ครึ่งหลัง): หน้าตอบแชทไม่มีเตือนหมดเวลาเลย** — ตั้งใจตัดออกใช่ไหม ถ้าใช่คงไว้แบบนั้น ถ้าไม่ใช่ต้องเอาเตือนกลับเข้าไป

## 4. ทางแก้ (คนใช้เห็นอะไรเปลี่ยน)

1. ปุ่มค้นบนมือถือเปิดแผงค้นหาเดียวกับคอม พิมพ์ เลือก ไปปลายทางได้
2. คนตอบแชทไม่เห็นเมนูนัดหมายแล้ว (D1: ซ่อนเมนู)
3. ปุ่มออกจากแถบข้างเป็นปุ่มจริง มีถามก่อนออกเหมือนรูปโปรไฟล์ ใช้คีย์บอร์ดได้
4. ตอนกำลังรอ กด Escape/คลิกพื้นหลัง/ปุ่มกากบาทไม่ปิดหน้าต่าง และมีข้อความบอกว่า "กำลังทำรายการ ปิดหน้าต่างไม่ได้ยกเลิกคำสั่ง"
5. กดลบเบิ้ลตอนเน็ตช้า ส่งคำสั่งครั้งเดียว ปุ่มแสดงว่ากำลังลบ
6. เมนูมือถือกด Tab ไม่หลุดไปข้างหลัง กด Escape ปิดได้ โฟกัสกลับปุ่มเดิมตอนปิด
7. เตือนหมดเวลาใช้หน้าต่างกลาง มีชื่อให้โปรแกรมอ่านจอ โฟกัสย้ายเข้าหน้าต่าง กด Escape/ต่อเวลาได้ด้วยคีย์บอร์ด ครอบหน้าตอบแชทด้วย (D2)
8. พิมพ์ค้นหารัวๆ หน้าจอแสดงผลตามคำค้นล่าสุดเสมอ

## 5. User stories (ย่อ)

1. ในฐานะคนใช้มือถือ อยากกดค้นหาแล้วเจอเหมือนบนคอม
2. ในฐานะคนตอบแชท อยากเห็นแค่เมนูที่เข้าได้จริง
3. ในฐานะแอดมิน อยากให้ปุ่มออกถามก่อนทุกที่กันมือลั่น
4. ในฐานะแอดมิน อยากมั่นใจว่ากดลบครั้งเดียวคือครั้งเดียว
5. ในฐานะคนใช้คีย์บอร์ด อยากใช้เมนูมือถือกับทุกหน้าต่างได้ครบ
