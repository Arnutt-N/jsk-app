## Task 1 — `backend/scripts/collect_preflight_db_evidence.py` (new)

**ACTION:** Create the read-only evidence collector per PRD FR1.

**MIRROR:** `backend/scripts/db_target.py` (arg parsing, `TARGET_ENV_FILES` mapping,
`main() -> int` + `raise SystemExit(main())`) and `backend/scripts/verify_db.py`
(read-only reporting style, `--output`). Read both before writing.

**IMPORTS:** stdlib `argparse/json/sys/datetime/pathlib` + `asyncpg` (already a
dependency via SQLAlchemy async). Read `DATABASE_URL` from the target env file the
same way `show_active_db_target.read_database_url` does — reuse that function.
Convert `postgresql+asyncpg://` → plain DSN for `asyncpg.connect`.

**IMPLEMENT:**
- `asyncpg.connect(dsn, timeout=10)`; immediately
  `SET default_transaction_read_only = on` (session-level; catch failure on
  read-only replicas gracefully).
- Queries (all SELECT):
  - `SELECT current_schema(), version()`
  - `SELECT version_num FROM alembic_version` (handle missing table → "not stamped")
  - `SELECT extversion FROM pg_extension WHERE extname='pg_stat_statements'`
  - top-N tables: `pg_class` join `pg_namespace` where `relkind='r'` and
    `nspname='public'`, `pg_total_relation_size`, `reltuples::bigint`, order by size
    desc limit N (`--limit`, default 20). Render size via `pg_size_pretty`.
  - slow statements (only if extension present): `SELECT queryid, calls,
    total_exec_time, mean_exec_time FROM pg_stat_statements ORDER BY
    total_exec_time DESC LIMIT N` — **never select the `query` column**.
  - ORM-vs-live presence check: import table names from
    `app.models` metadata **without importing app.main** — use
    `from app.models import Base` equivalent (verify actual import path first; if
    importing models pulls settings, set `ENV_FILE` before import exactly like
    `db_target.build_subprocess_env`). Compare `Base.metadata.tables.keys()` vs
    `information_schema.tables` and report missing ones as findings.
- Redaction: error handler catches connection errors and prints
  `error: cannot connect to target '<local|remote>' database within 10s` — never
  echo the DSN. Output header shows target name + UTC timestamp only.
- `--json` mode emits one JSON object mirroring the markdown sections.

**GOTCHA:** asyncpg needs an event loop — wrap in `asyncio.run()`. `reltuples` is an
estimate; label it "estimated rows". `alembic_version` may contain >1 row (multiple
heads) — render all.

**VALIDATE:**
```bash
cd backend
./venv_linux/bin/python scripts/collect_preflight_db_evidence.py --target local
./venv_linux/bin/python scripts/collect_preflight_db_evidence.py --target local --json | ./venv_linux/bin/python -m json.tool
sudo service postgresql stop && time ./venv_linux/bin/python scripts/collect_preflight_db_evidence.py --target local; echo "exit=$?"   # expect exit=1, <15s
sudo service postgresql start
grep -nE "postgresql(\+asyncpg)?://|password" <(./venv_linux/bin/python scripts/collect_preflight_db_evidence.py --target local)  # expect no matches
```

**FIRST:** `grep -rn "from app.main import\|from conftest import\|import conftest" backend/tests/` — map every consumer of the module-level `app` before touching it.
