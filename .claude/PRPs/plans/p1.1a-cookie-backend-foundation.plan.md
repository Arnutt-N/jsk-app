# Plan: P1.1a Cookie Backend Foundation (PR 2A)

## Summary
Wire `COOKIE_AUTH_MODE` (bearer|dual|cookie) into real behavior: HttpOnly
cookie issuance, server-side refresh sessions with rotation + reuse detection,
double-submit CSRF, an audited rate-limited Bearer→cookie migration endpoint,
CORS hardening, and a single-use WebSocket auth ticket. Backend only; with the
default `bearer` mode every existing request/response stays byte-identical.

## User Story
As an admin-console operator, I want my session credentials kept out of
JavaScript-readable storage and revocable server-side, so that an XSS or a
stolen refresh token cannot silently become a permanent session.

## Problem → Solution
Stateless 7-day refresh JWTs + localStorage tokens + no CSRF/no cookie code →
dual-mode cookie foundation (dark-shipped behind `COOKIE_AUTH_MODE=bearer`).

## Patterns to Mirror

### TZ_AWARE_DATETIME (bites asyncpg if missed)
```python
# SOURCE: backend/app/models/audit_log.py:25-29
created_at = Column(
    DateTime(timezone=True),
    default=lambda: datetime.now(timezone.utc),
    index=True,
)
```
Every timestamp column in the two new tables MUST be `DateTime(timezone=True)`
and every comparison bind MUST be tz-aware (`datetime.now(timezone.utc)`).

### MIGRATION_GUARDS
```python
# SOURCE: backend/alembic/versions/v2w3x4y5z6a7_unique_open_chat_session.py:28-35,62-74
def _index_exists(connection, index_name: str) -> bool: ...
def upgrade() -> None:
    connection = op.get_bind()
    if _index_exists(connection, INDEX_NAME):
        return
```
Use `sa.inspect(connection).has_table("auth_sessions")` guards the same way.

### AUDIT_WRITE (P0.3 idiom — audit + mutation in ONE commit where endpoint owns the commit)
```python
# SOURCE: backend/app/core/audit.py:110-149  (flushes, caller commits)
await create_audit_log(db, admin_id=user.id, action="...", resource_type="auth",
                       resource_id=str(user.id), details={...})
await db.commit()
```
Auth endpoints own their transaction: mutation (session row) + audit row +
`db.commit()` together. Never put secrets/tokens in `details` (P0.3 fail-closed
redaction philosophy — identifiers and outcomes only).

### SETTINGS_MONKEYPATCH (tests)
```python
# SOURCE: backend/tests/test_liff_token.py:17-18

```

    return create_async_engine(str(settings.DATABASE_URL), poolclass=NullPool)

Any direct-DB assertion in an async test must use a throwaway NullPool engine.

### Task 4: auth_session_service.py
- **ACTION**: All session/ticket DB logic in one service module (functions taking `db: AsyncSession`; no class needed — mirror `create_audit_log`'s free-function style).
- **IMPLEMENT**:
  - `_hash(value: str) -> str` = `hashlib.sha256(value.encode()).hexdigest()`.
  - `create_session_family(db, user_id) -> tuple[refresh_jwt, family_id]`:
    uuid4 jti + family; insert row (`expires_at = now + REFRESH_TOKEN_EXPIRE_DAYS`); return JWT from Task 2.
  - `rotate_refresh_session(db, token_payload) -> RotationResult`:
    atomic claim —
    ```python
    stmt = (update(AuthSession)
        .where(AuthSession.token_hash == _hash(jti),
               AuthSession.status == STATUS_ACTIVE,
               AuthSession.expires_at > now)
        .values(status=STATUS_ROTATED, last_used_at=now)
        .returning(AuthSession.id, AuthSession.family_id, AuthSession.user_id))
    ```
    row returned → insert successor row (same family), link `replaced_by_id`,
    return new refresh JWT. No row → `SELECT` by hash: found (rotated/revoked/expired-active)
    → **reuse**: `UPDATE auth_sessions SET status='revoked' WHERE family_id=... AND status='active'`,
    return `REUSE_DETECTED`; not found → `INVALID`.
  - `revoke_family(db, family_id) -> int` (row count, for logout).
  - `mint_ws_ticket(db, user_id) -> str`: raw `secrets.token_urlsafe(32)`,
    store hash, `expires_at = now + timedelta(seconds=60)`; opportunistic
    cleanup in same call: `DELETE FROM ws_tickets WHERE expires_at < now - interval '1 day'`
    and `DELETE FROM auth_sessions WHERE expires_at < now - interval '30 days'`
    (bounded tables; PRD open question — 30 days ratified at review).
  - `claim_ws_ticket(db, raw) -> Optional[int]` (user_id):
    `UPDATE ws_tickets SET used_at=now WHERE token_hash=:h AND used_at IS NULL AND expires_at > :now RETURNING user_id`.
- **MIRROR**: TZ_AWARE_DATETIME binds; SQLAlchemy 2.0 style (`select/update` from `sqlalchemy`) as in `deps.py:89`.
- **GOTCHA**: caller commits (endpoint owns transaction — AUDIT_WRITE pattern). Service only flushes.
- **VALIDATE**: FR8 tests 4/5/9.
