## Task 1 — guards in `backend/app/core/config.py` + LIFF fail-closed

**IMPLEMENT (config.py):**
- Import `model_validator` from pydantic. Add constants near the top:
  `_MIN_SECRET_KEY_LENGTH = 32` and `_PLACEHOLDER_SECRET_KEYS = frozenset({...})`
  (lowercased; include `change_this_to_a_secure_random_string`, `changeme`,
  `change_this`, `secret`, `secret_key`).
- `@model_validator(mode="after") def _enforce_production_guards(self)`:
  - return self immediately unless `self.ENVIRONMENT.strip().lower() == "production"`.
  - collect violations (list of one-line strings, each naming the env var + remedy,
    NEVER the configured value):
    - `DEV_AUTH_BYPASS` truthy → "DEV_AUTH_BYPASS must be disabled in production — remove it from the environment."
    - `SECRET_KEY` stripped shorter than 32 or lowercased in placeholder set →
      "SECRET_KEY is too weak for production — set a random value of at least 32 characters (e.g. openssl rand -hex 32)."
    - `LINE_LOGIN_CHANNEL_ID` blank → "LINE_LOGIN_CHANNEL_ID must be set in production for LIFF token verification."
    - `ENCRYPTION_KEY` blank → "ENCRYPTION_KEY must be set in production — generate a Fernet key."
  - if violations: `raise ValueError("Unsafe production configuration:\n" + "\n".join(f"- {v}" for v in violations))`.
- Keep everything else untouched (defaults stay development-friendly).

**IMPLEMENT (liff.py `verify_liff_token`):** first statement — if
`not settings.LINE_LOGIN_CHANNEL_ID.strip()`: `logger.error("LINE_LOGIN_CHANNEL_ID is not configured; cannot verify LIFF ID token")` then
`raise HTTPException(status_code=503, detail="LIFF verification unavailable: server misconfiguration")`.
Match the endpoint file's existing import/log style. No other liff.py changes.

**GOTCHA:** `settings = Settings(_env_file=resolve_env_file())` at config.py module
level means a bad production env now fails at import — that IS the fail-closed
intent, but make sure no test imports config with `ENVIRONMENT=production` ambient.
Check `backend/tests` for any test that sets ENVIRONMENT=production via env (not
constructor) before assuming.
