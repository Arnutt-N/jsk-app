# PRD E: เพิ่มหน่วยงาน + หมวดแจ้งเบาะแสยาเสพติด

## Problem Statement

ระบบคำร้องปัจจุบันมี **3 หน่วยงานหลัก** (ศูนย์ยุติธรรมชุมชน, ศูนย์ดำรงธรรม, สถานีตำรวจภูธร) และ **หมวดคำร้องหลัก** (ร้องเรียน/ร้องทุกข์, ขอความช่วยเหลือ, ฯลฯ) แต่มีช่องว่าง 2 จุด:

1. **ขาดหน่วยงานระดับชุมชน** — กลุ่มหน่วยงานระดับชุมชน (กำนัน, ผู้ใหญ่บ้าน, จิตอาสา, ผู้นำชุมชน) ซึ่งเป็นกลไกสำคัญในการเข้าถึงประชาชนในระดับรากหญ้า ไม่มีในระบบ ทำให้ต้องส่งคำร้องผ่านช่องทางอื่นที่ไม่เป็นทางการ
2. **ขาดหมวดแจ้งเบาะแสยาเสพติด** — ปัญหายาเสพติดเป็นวาระแห่งชาติ แต่ไม่มีหมวดเฉพาะ ทำให้เบาะแสยาเสพติดถูกจัดรวมอยู่ใน "ร้องเรียน/ร้องทุกข์" ซึ่งไม่สะท้อนความเร่งด่วนและความเฉพาะทางของปัญหา

## Evidence

- โครงสร้างหน่วยงานปัจจุบัน: `backend/app/schemas/service_request.py` มี `agency` field แต่จำกัดเฉพาะ 3 หน่วยงานหลัก
- หมวดหมู่ปัจจุบัน: `frontend/lib/constants/request-categories.ts` (ถ้ามี) หรือ inline ใน form ไม่มี "แจ้งเบาะแสยาเสพติด"
- User feedback: ต้องการเพิ่มช่องทางระดับชุมชนและหมวดเฉพาะสำหรับยาเสพติด

## Proposed Solution

### Part A: เพิ่มหน่วยงานระดับชุมชน
เพิ่มตัวเลือกใน dropdown `agency`:
- **หน่วยงานระดับชุมชน (กำนัน/ผู้ใหญ่บ้าน/จิตอาสา/ผู้นำชุมชน)** — เป็น 1 รายการหลักที่มี label รวม ไม่แยกเป็น 4 รายการ

### Part B: เพิ่มหมวด "แจ้งเบาะแสยาเสพติด" (หมวดหลัก)
เพิ่มเป็นหมวดหลักใน dropdown `category` **เรียงลำดับไว้ก่อน** "ร้องเรียน/ร้องทุกข์"

**ปัญหาย่อย** (เก็บใน `details` JSONB field):
1. ผู้เสพ/ผู้ป่วยที่เฝ้าระวัง/อันตราย
2. ขอความช่วยเหลือบำบัดผู้เสพ
3. ครอบครัวที่ต้องเข้าช่วยเหลือจากผลกระทบยาเสพติด
4. แจ้งเบาะแสยาเสพติด

### Part C: Workflow เพิ่มเติม
ใช้ workflow เดิม + เพิ่ม **ตัวเลือกส่งต่อ** (escalation) ในหน้า request detail:
- ป.ป.ส. (สำนักงานคณะกรรมการป้องกันและปราบปรามยาเสพติด)
- ตำรวจ
- กรมการปกครอง
- กำหนดเอง (custom)

## Key Hypothesis

We believe **การเพิ่มหน่วยงานระดับชุมชน + หมวดแจ้งเบาะแสยาเสพติด** จะ **เพิ่มการเข้าถึงบริการของรัฐและช่วยให้เบาะแสยาเสพติดได้รับการจัดการอย่างเร่งด่วน** for **ประชาชนในพื้นที่ + เจ้าหน้าที่ระดับชุมชน**.

We'll know we're right when:
- ประชาชนสามารถเลือกหน่วยงานระดับชุมชน (กำนัน/ผู้ใหญ่บ้าน/ฯลฯ) ได้
- เบาะแสยาเสพติดถูกจัดหมวดหมู่แยกชัดเจน
- เจ้าหน้าที่สามารถส่งต่อให้หน่วยงานเฉพาะทาง (ป.ป.ส./ตำรวจ) ได้ภายใน 1 คลิก

## What We're NOT Building

- **เพิ่ม role ใหม่** — ใช้ role เดิม (USER สำหรับผู้ร้อง, ADMIN/AGENT สำหรับเจ้าหน้าที่)
- **Real-time notification สำหรับยาเสพติด** — ใช้ระบบ notification เดิม (LINE/Telegram) ไม่เพิ่ม channel ใหม่
- **Anonymous reporting system** — ยังต้องระบุตัวตนผู้ร้อง (ถ้าต้องการ anonymous จริง ต้องสร้างระบบแยก)
- **Database schema ใหม่** — ใช้ `agency` field เดิม + `details` JSONB เดิม ไม่เพิ่ม column
- **SLA เฉพาะสำหรับยาเสพติด** — ใช้ SLA เดิม (ถ้าต้องการ SLA แยก ต้องทำ PRD แยก)

## Users & Context

**Primary User**
- **Who**: ประชาชนในพื้นที่ (ผู้ร้อง) + เจ้าหน้าที่ระดับชุมชน (กำนัน/ผู้ใหญ่บ้าน/จิตอาสา/ผู้นำชุมชน)
- **Current behavior**: ต้องส่งคำร้องผ่านศูนย์ยุติธรรมชุมชน/ศูนย์ดำรงธรรม/สถานีตำรวจเท่านั้น ไม่มีช่องทางระดับชุมชน
- **Trigger**: ต้องการแจ้งเบาะแสยาเสพติดหรือร้องเรียนปัญหายาเสพติดในพื้นที่
- **Success state**: สามารถเลือกหน่วยงานระดับชุมชน + หมวดแจ้งเบาะแสยาเสพติด + ส่งต่อให้หน่วยงานเฉพาะทางได้

## Implementation Plan

### Phase 1: Frontend - เพิ่มหน่วยงานใหม่
1. เพิ่ม 4 หน่วยงานใน dropdown `agency` (กำนัน, ผู้ใหญ่บ้าน, จิตอาสา, ผู้นำชุมชน)
2. เรียงลำดับให้เหมาะสม (หน่วยงานระดับชุมชนก่อนหน่วยงานหลัก)

### Phase 2: Frontend - เพิ่มหมวด "แจ้งเบาะแสยาเสพติด"
3. เพิ่มหมวดหลัก "แจ้งเบาะแสยาเสพติด" ใน dropdown `category` (เรียงไว้ก่อน "ร้องเรียน/ร้องทุกข์")
4. เพิ่ม subcategory dropdown เมื่อเลือก "แจ้งเบาะแสยาเสพติด" (4 ปัญหาย่อย)

### Phase 3: Backend - รองรับข้อมูลใหม่
5. ตรวจสอบว่า `agency` field รับค่าใหม่ได้ (string, ไม่มี constraint)
6. ตรวจสอบว่า `details` JSONB เก็บ subcategory ได้
7. (Optional) เพิ่ม validation สำหรับ subcategory ถ้าจำเป็น

### Phase 4: Frontend - Workflow ส่งต่อ
8. เพิ่มปุ่ม "ส่งต่อหน่วยงานเฉพาะทาง" ในหน้า request detail (เฉพาะหมวดแจ้งเบาะแสยาเสพติด)
9. เพิ่ม dropdown เลือกหน่วยงาน: ป.ป.ส. / ตำรวจ / กรมการปกครอง / กำหนดเอง
10. Update status field เมื่อส่งต่อ (เช่น: `status='ESCALATED'` หรือใช้ `details.escalation_agency`)

### Phase 5: Tests
11. Unit test: dropdown แสดงหน่วยงานใหม่ + หมวดใหม่
12. E2E test: สร้างคำร้องแจ้งเบาะแสยาเสพติด → ส่งต่อ → status เปลี่ยน
