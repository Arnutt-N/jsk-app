# PRD: ฟอร์มขอใช้งาน + ลืมรหัสผ่านทางอีเมล

## ปัญหา (ภาษาคน)
- ตอนนี้เพิ่มคนใช้ได้ทางเดียวคือแอดมินพิมพ์เพิ่มเองทีละคน ถ้าคนขอเยอะแอดมินทำไม่ทัน
- พนักงานจำชื่อผู้ใช้ไม่ได้ก็เข้าไม่ได้ ต้องโทรตามแอดมินรีเซ็ตให้ (ของเดิมมีปุ่มรีเซ็ตโดยแอดมินอยู่แล้ว)

## เป้าหมาย
1. มีฟอร์มให้คนกรอกขอใช้งานได้ แล้วแอดมินกดอนุมัติ/ปฏิเสธในหน้าจัดการ
2. พนักงานกดลืมรหัสผ่านเองได้ รับลิงก์ทางอีเมล โดยแอดมินยังรีเซ็ตให้ได้เหมือนเดิม

## ขอบเขต
- ทำ: ฟอร์มขอใช้สาธารณะ (ไม่แปะลิงก์ในเมนู แชร์ URL ให้คนที่ต้องการ), คิวรออนุมัติหลังบ้าน, อนุมัติสร้างบัญชีพร้อมรหัสเริ่มต้น, ปฏิเสธพร้อมเหตุผล, ฟอร์มลืมรหัสผ่าน, หน้าตั้งรหัสใหม่จากลิงก์อีเมล, ส่งอีเมลผ่าน SMTP เดิมของระบบ
- ไม่ทำ: สมัครแล้วใช้ได้ทันที (ต้องอนุมัติก่อนเสมอ), ขอสิทธิ์ Super Admin/Admin ผ่านฟอร์ม (ขอได้แค่ Operator/Director/Head), แนบไฟล์, CAPTCHA (ใช้ rate-limit แทน ถ้าโดนสแปมค่อยเพิ่ม)

## ความปลอดภัย
- คำขอใหม่เข้าไม่ได้จนกว่าแอดมินอนุมัติ ไม่สร้างบัญชีล่วงหน้า
- ฟอร์มสาธารณะจำกัดจำนวนครั้งต่อ IP กันกรอกขยะ
- ลืมรหัสผ่านตอบสำเร็จเสมอแม้ไม่เจออีเมล (ไม่บอกว่าคนนี้มีตัวตนหรือไม่)
- ลิงก์รีเซ็ตมีอายุ 30 นาที ใช้ได้ครั้งเดียว รหัสผ่านใหม่ขั้นต่ำ 8 ตัวอักษร
- ADMIN อนุมัติได้เฉพาะ Operator, Director/Head ต้อง SUPER_ADMIN (กฎเดียวกับหน้าจัดการผู้ใช้)

## เกณฑ์รับงาน
- กรอกฟอร์มครบได้เลขคำขอ ชื่อผู้ใช้ซ้ำกับของเดิมอนุมัติไม่ผ่านพร้อมข้อความชัดเจน
- อนุมัติแล้วล็อกอินด้วยชื่อหรืออีเมลได้ทันที
- ขอลิงก์รีเซ็ตแล้วอีเมลเข้า (ถ้าตั้งค่า SMTP ไว้) กดลิงก์ตั้งรหัสใหม่ล็อกอินได้ ลิงก์เก่าใช้ซ้ำไม่ได้
- เทสหลังบ้าน + หน้าบ้านผ่าน ชุดเดิมไม่พัง
